# Install

## Ubuntu / Debian

Choose the package that matches your system architecture:

- `*_amd64.deb` for `x86_64` / `amd64`
- `*_arm64.deb` for `arm64` / `aarch64`

Check your architecture with:

```bash
dpkg --print-architecture
```

Install with:

```bash
sudo apt install ./package-name.deb
```

## macOS

Open the `.dmg` file and move **Blabler Desktop** to **Applications**.

## Windows

Run the `.msi` installer and follow the setup steps.
